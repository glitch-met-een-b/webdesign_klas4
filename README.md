# Webdesign

In deze module leer je stap voor stap hoe websites worden opgebouwd en hoe je zelf een website maakt met HTML en CSS. Je gebruikt daarbij GitHub en Codespaces om je code te schrijven, bekijken en bewaren.

Bij deze repository horen:
- het lesboek met theorie;
- het werkboek met opdrachten;
- deze repository met de bestanden waarin je werkt.

## Aan de slag

### 1. Open je repository

Je opent je repository via GitHub.

Weet je niet meer hoe dat moet?  
Lees **paragraaf 2.4 Repo openen** in het lesboek.

### 2. Open je Codespace

Gebruik steeds dezelfde Codespace voor deze opdracht. Maak dus niet iedere les een nieuwe aan.

Weet je niet meer hoe je een Codespace opent?  
Gebruik **paragraaf 2.3 Je eigen repo krijgen** als je nog geen Codespace hebt.  
Gebruik daarna **paragraaf 2.4 Repo openen** om verder te werken.

### 3. Bekijk je website

Om te controleren wat je code doet, open je de website in de preview.

Weet je niet meer hoe dat moet?  
Gebruik **paragraaf 2.5 De website zien**.

### 4. Werk aan de opdrachten

Volg de opdrachten in het werkboek in de aangegeven volgorde.

Verander alleen bestanden die bij de opdracht horen.  
Lees de genoemde theorie uit het lesboek wanneer het werkboek daarnaar verwijst.

### 5. Bewaar je werk

Sla je bestanden tijdens het werken regelmatig op.

Als je een onderdeel hebt afgerond:
1. controleer je werk;
2. schrijf een duidelijk commitbericht;
3. commit je veranderingen;
4. synchroniseer je veranderingen met GitHub.

Gebruik hiervoor **paragraaf 2.8 Veranderingen opslaan**.

Weet je niet meer hoe je een goed commitbericht schrijft?  
Lees **paragraaf 2.9 Goede commit-berichten maken**.

## Belangrijk

- Gebruik steeds dezelfde repository en Codespace.
- Verwijder geen bestanden tenzij een opdracht dat vraagt.
- Verander bestandsnamen alleen wanneer een opdracht dat vraagt.
- Controleer regelmatig of je website nog werkt.
- Commit je werk na een afgerond onderdeel.
- Loopt iets niet zoals verwacht? Kijk eerst in het lesboek, misschien is het bedoeld. Anders kun je vragen stellen aan de docent.
